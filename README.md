# Repository for Mutation Technical Debt definition

This repository contains a set of C programs, scripts, and collected raw data illustrating the computation of Mutation Technical Debt (MTD).

Repository high level directory structure is below:

```
mtd/
├── experiments			
│   ├── data            # Collected experimental data and results
│   ├── graphs          # Generated visualizations and plots
│   ├── programs        # Subject programs used in the experiment
│   ├── reports         # Generated mutation testing reports
│   └── scripts         # Automation scripts for data collection
├── historical-data
│   ├── c               # Previous data from C programs
│   └── python          # Previous data from Python programs
├── images              # Screenshots used in the paper
├── tool                # ProteumIM version used to collect data
└── README.md           # This file
```

Below, we provide additional information about each directory/subdirectory's content


## `experiments` 

Contains all data related to the experimental study:

- `data/`: Contains all collected experimental data, including mutation scores, test case metrics, and CSV files with raw results
- `graphs/`: Stores generated charts and visualizations of the experimental results
- `programs/`: Houses the subject programs under test, along with their test session files, test cases, equivalent mutant information, and general ProteumIM reports for mutation analysis at different stages (initial, final, SSDL)
- `reports/`: Contains a synthesis of ProteumIM reports to perform the calculation of all subject programs
- `scripts/`: Includes shell scripts for automating the experimental workflow and data collection process. The script folder also includes a [README.md](experiments/scripts/README.md) file that outlines the order for running each data-collection script. It also contains a [PROTEUM.md](experiments/scripts/PROTEUM.md) file with basic ProteumIM commands to generate data for a single program.

## `historical-data`

This folder contains previously collected data from C and Python programs, which allows us to gain insights into the percentage of equivalent mutants generated by each mutation operator.

## `images`

The `images` folder contains images used in the paper.

## `tool`

Folder containing the binary version of the ProteumIM mutation testing tool used in the experiment.
Moreover, the folder contains a [README.md](tool/README.md) file with information on hardware resources, compilers, and the operating system version used in the experiment.
